# 傳說對決 10-Ban BP 模擬與即時勝率分析系統 (AoV BP Simulator)

對應《Garena 傳說對決》（Arena of Valor）**2026 十週年「裂隙穿梭」版本** 的互動式 10-Ban（雙方各 5 Ban）禁選模擬與戰術分析工具。

## 主要功能

- **132 位英雄／定位資料庫**：涵蓋十週年新角（艾薇塔、拓冥、元流之子四型態）、雙生與重製英雄（普雷塔、狄拉克、刀鋒寶貝、布萊恩、少司緣、比洛爾、朵莉亞、森圖爾特、凱恩等）。
- **三種 5-Ban BP 模式與自動分區權重**：
  - `賽事 5-Ban (3+2)` / `進階 5-Ban (2+3)`：偏重職業賽事優先度與體系連動。
  - `自由選禁 (排位賽)`：切換為排位環境權重與勝率／Ban 率優先序，突顯排位強勢上分與滾雪球角。
- **遊戲內風格 BP 禁選介面**：暗藍金競技科技視覺、頂部雙方 5 Ban 位與勝率拔河條、左右 5 樓出戰欄、英雄預選與金色鎖定按鈕。
- **即時勝率走向與前／中／後期戰力曲線**：每手禁用或選角即時更新第 1–20 手藍方勝率折線圖。
- **智慧戰術建議與彈性搖擺配對**：
  - 採用最佳二分圖匹配（Maximum Matching）支援如 **愛麗絲中路、銀晝輔助、薩尼凱撒** 等合理彈性搖擺。
  - AI 禁用（Ban）自動偵測敵方**確切已鎖定位置**，不再對敵方已定案的分路浪費 Ban 位。

## 快速使用

直接用瀏覽器開啟 `index.html` 即可於本機離線／線上執行（無需建置工具）。
